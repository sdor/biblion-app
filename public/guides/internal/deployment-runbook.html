#DigitalOcean Droplet Deployment & Operation Runbook

Audience: DevOps Engineers & Release Managers

Maintained by: Biblion Evangelist

#1. Droplet Infrastructure

  • Host: DigitalOcean Droplet (159.223.191.180 / biosystechnologies.com)
  • SSH User: biblion (configured via ~/.ssh/macbookpro and ~/.ssh/id_ed25519)
  • Backend Path: /var/www/biblion-api/current
  • Service: systemd: biblion-api.service
  • Database: PostgreSQL (database biblion)
  • Reverse Proxy: Nginx with SSL termination

#2. Pre-Deployment Rules & Checklist

CRITICAL INVARIANT: Deployments to production occur exclusively from the main branch.

Before running deployment:

  1. Confirm main branch on all workspace repos:

```bash

git -C biblion-app rev-parse --abbrev-ref HEAD

git -C biblion-api rev-parse --abbrev-ref HEAD

```

  1. Verify working trees are clean (no untracked files or uncommitted changes):

```bash

git -C biblion-app status --short

git -C biblion-api status --short

```

  1. Verify all changes in development have been tested and merged into main.

#3. Deployment Procedure

Execute deployment script from the workspace:

bash
./scripts/deploy.sh

Or perform step-by-step deploy via SSH:

bash
ssh biblion@159.223.191.180 "bash -l -c 'cd /var/www/biblion-api/current && git pull origin main && bundle install && RAILS_ENV=production bin/rails db:migrate && sudo systemctl restart biblion-api'"

#4. Post-Deployment Verification & Diagnostics

  1. Service Status:

```bash

ssh biblion@159.223.191.180 "sudo systemctl status biblion-api.service"

```

  1. Inspect Service Logs:

```bash

ssh biblion@159.223.191.180 "journalctl -u biblion-api.service -n 50 --no-pager"

```

  1. Nginx Health:

```bash

ssh biblion@159.223.191.180 "sudo nginx -t && sudo systemctl reload nginx"

```

  1. Public Endpoint Check:

```bash

curl -I https://biosystechnologies.com/health

```
