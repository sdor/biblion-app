#Internal Developer Onboarding Guide

Target Audience: Biblion Core Engineers & AI Developers

Maintained by: Biblion Evangelist

#1. System Overview

Biblion is a specialized citation, bibliography, and PubMed research platform. It consists of:

  • biblion-app/: Standalone Angular client serving as both a Microsoft Word Add-in (taskpane) and web application.
  • biblion-api/: Ruby on Rails 8 API backend managing users, sessions, bibliography synchronization, and Lemon Squeezy billing.
  • biblion-specs/: Spec-Driven Development (SDD) repository containing behavioral scenarios and technical contracts.
  • scripts/ & nginx/: Deployment and droplet management infrastructure.

#2. Workspace & Git Conventions

CRITICAL RULE: The root directory ~/workspace/biblion is a multi-repo container, not a git repository.

  • Never run git commands from the root.
  • Target repositories individually:

```bash

git -C biblion-app status

git -C biblion-api status

```

  • Note host quirk: On macOS, use /opt/homebrew/bin/git if /usr/local/bin/git fails.

#3. Spec-Driven Development (SDD)

All non-trivial feature development adheres to SDD under biblion-specs/:

  1. Behavioral Scenarios are partitioned into:
  • Implemented Scenarios: Functioning, covered by automated tests.
  • Proposed Scenarios: New requirements or enhancements.
  1. Scenarios carry Status: [PROPOSED] or Status: [APPROVED].
  2. Engineers only implement [APPROVED] scenarios.

#4. Deployment & Infrastructure

  • Deployment Rules: Only main branches are deployed to production. Feature or development branches must be merged into main after verification.
  • Production Droplet: DigitalOcean droplet at 159.223.191.180 (biosystechnologies.com).
  • Rails API: Deployed at /var/www/biblion-api/current under systemd service biblion-api.service.
  • CLI / Rails Console on Droplet: Requires a login shell for rbenv:

```bash

ssh biblion@159.223.191.180 "bash -l -c 'cd /var/www/biblion-api/current && RAILS_ENV=production bin/rails console'"

```
