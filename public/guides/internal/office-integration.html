#Angular Office.js Word Integration Guide

Audience: Frontend Engineers & Office Add-in Developers

Maintained by: Biblion Evangelist

#1. Overview & Runtime Environment

biblion-app is a standalone Angular 22 application running inside the Microsoft Word desktop or web taskpane via the Office.js JavaScript API.

  • Host Context: Microsoft Word 2016+ Desktop (Mac & Windows) and Word on the Web.
  • Taskpane Lifecycle: Bootstrapped when Word finishes initializing Office.onReady().
  • Local Persistence: IndexedDB holds local library references, cache, and unsynced mutations.

#2. Word Document Interaction: Content Controls

Biblion uses Word Content Controls (Word.ContentControl) to bind citation tags into the active document body:

  1. Citation Tags:
  • Each in-text citation is wrapped in a rich text Content Control.
  • Tag metadata includes biblion_citation_id, pmid, and bibliographic index.
  • Setting cannotEdit: false and cannotDelete: false preserves standard author editing capabilities while allowing programmatic document re-scans.
  1. Bibliography Container:
  • A dedicated Content Control tagged with biblion_bibliography is inserted at the user's cursor position or document end.
  • Whenever references change or citation styles are toggled, the bibliography block is cleared and regenerated in place without altering the surrounding manuscript text.

#3. Real-Time Cursor Tracking & Sentence Analysis

  • The WordCursorTracker service listens to selection change events in Word.
  • Evaluates current sentence boundaries to identify existing citations nearby.
  • Prevents duplicate citation insertions and assists in contextual query suggestions.

#4. Citation Style Formatting

  • Supports multiple citation styles (AMA, APA 7th, IEEE, Nature, Harvard).
  • Dynamic switching: When a style is updated in the Biblion settings panel, an automated document traversal updates in-text markers (e.g., superscripts [1] vs author-date (Smith et al., 2024)) and reformats the bibliography.
